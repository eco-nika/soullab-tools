# brand/ 문서 작업 지침

## 적용 범위

이 지침은 `brand/` 안의 모든 문서에 적용합니다. 다른 폴더에서 브랜드 정보를 사용할 때도 이 폴더의 확정된 내용을 기준으로 삼습니다. 최상위 `AGENTS.md`를 함께 따릅니다.

## 읽는 순서

1. 최상위 `AGENTS.md`
2. `brand/AGENTS.md` — 이 지침
3. `identity.md` — 브랜드와 운영자 정보
4. `voice.md` — 말투와 표현 기준
5. `audience.md` — 대상과 예시 작성 기준
6. `content.md` — 콘텐츠 주제와 상품 안내 기준

## 문서별 역할

- `identity.md`: 브랜드 표기, 세미콜론의 의미, 운영자 경력, 공식 사이트·계정을 기록합니다.
- `voice.md`: 자연스러운 한국어 말투, 피할 표현, 문장 예시를 관리합니다.
- `audience.md`: 확인된 대상과 대상별 실무 예시를 관리합니다. 예시를 실제 고객 사례나 성과처럼 쓰지 않습니다.
- `content.md`: 콘텐츠 방향, 상품 목록, 가격과 상담 안내 기준을 관리합니다. 채널별 실제 원고는 `channels/`에 둡니다.

## 작성·수정 원칙

- 사용자가 제공하거나 확인한 정보만 사실로 기록합니다. 없는 경력·성과·후기·고객사·가격·연락처·신청 링크를 지어내지 않습니다.
- 확인되지 않은 정보는 `확인 필요`로 표시하거나 생략합니다. 예시와 제안은 사실과 구분합니다.
- 따뜻하고 간결한 자연스러운 한국어를 사용합니다. 거창한 표현, AI 티 나는 상투어, 근거 없는 효과 보장을 피하고 구체적인 예시를 씁니다.
- 브랜드 표기는 `Soul;Lab(소울랩)`, 운영자 호칭은 `니카쌤`을 기준으로 합니다. 사용자가 요청하지 않은 재브랜딩은 하지 않습니다.
- 문서의 역할에 맞는 파일만 수정합니다. 같은 정보를 여러 문서에 중복하기보다 기준 문서를 참조합니다.
- 비밀번호, API 키, 결제 비밀값, 개인정보는 이 폴더에 기록하지 않습니다.

## 변경 시 기록

- 각 문서를 수정할 때 문서 하단의 `변경 기록`에 한국 시간 기준 날짜, 바뀐 내용, 근거를 짧게 남깁니다.
- 브랜드 사실을 바꿀 때는 사용자 요청 등 확인 가능한 근거를 기록합니다. 초안 제안을 확정 정보로 바꾸지 않습니다.
- 관련 문서의 충돌 여부를 확인하고, 요청 범위의 변경만 커밋합니다. 커밋 메시지에 무엇을 바꿨는지 명시합니다.

## 변경 기록

- 2026-10-12: 사용자 요청에 따라 적용 범위, 읽는 순서, 문서 역할, 작성 원칙과 변경 기록 규칙을 만들었습니다.
