# 대상

## 확인된 대상

- 소상공인
- 재직자
- 구직자
- 광고·방송·IT 기획 실무자

## 대상별 예시 작성

아래는 콘텐츠를 작성할 때 사용할 수 있는 실무 예시입니다. 실제 고객의 요구, 제공 중인 개별 강좌, 검증된 성과를 뜻하지 않습니다.

| 대상 | 구체적인 실무 예시 |
| --- | --- |
| 소상공인 | 가게 행사 안내, SNS 게시글, 고객 질문에 대한 답변 초안 |
| 재직자 | 회의 메모 정리, 보고서 목차, 반복 업무 절차 정리 |
| 구직자 | 경력 소개 문장, 포트폴리오 구성, 면접 질문 연습 |
| 광고 실무자 | 캠페인 기획 초안, 광고 문구 비교, 성과 보고서 구성 |
| 방송 실무자 | 프로그램 구성안, 대본 초안, 콘텐츠 홍보 문구 |
| IT 기획 실무자 | 요구사항 정리, 사용자 인터뷰 질문, 서비스 기획 문서 초안 |

연령, 지역, 소득, 숙련도, 실제 고객 비중은 확인되지 않았으므로 단정하지 않습니다. 독자가 당장 해야 하는 한 가지 과제를 중심으로 설명합니다.

## 변경 기록

- 2026-10-12: 사용자가 제공한 대상 목록과, 실제 사례가 아닌 실무 예시를 정리했습니다.
