쓰레드 글쓰기 목표 1개와 피드백 5개를 연결하고 벡터로 저장했습니다.

외부 API 키 없이 실행하는 로컬 해싱 벡터입니다. OpenAI 모델이나 학습된 신경망이 아니며, 비슷한 단어와 글자 조각을 찾습니다. 앞 5개 값이 0이어도 다른 차원에는 값이 있을 수 있습니다.

DB를 확인하고 있습니다.

agent_learning_goals

ID목표(goal)모델차원벡터 앞 5개 값

agent_learning_feedback

ID목표 ID평가글 초안(샘플)피드백 이유(샘플)

agent_learning_feedback_embeddings

ID피드백 ID모델차원벡터 앞 5개 값

목표와 피드백은 각각 벡터화했습니다. 피드백 벡터의 입력은 글 초안 + 좋음/나쁨 + 이유입니다. 저장·검색 구조를 확인하는 예제이며, 모델 재학습이나 글쓰기 규칙의 자동 승격 기능은 포함하지 않습니다. 이 공개 화면은 읽기 전용입니다.
