### GitHub 이력 기록 방식

추천기 코드는 원래 Git 워크트리의 `feature/prompt-recommender` 브랜치에서 개발하고 로컬 main에 병합했습니다. 해당 코드 전체는 GitHub main에 소스 스냅샷으로 먼저 업로드되었습니다.

이번 GitHub PR은 이미 업로드된 서비스의 변경 이력을 추가하고 GitHub에서 확인할 수 있는 merge 커밋·태그·릴리스를 만드는 작업입니다. 원래 로컬 커밋 이력을 그대로 전송한 것은 아닙니다. 실행 코드와 게시된 사이트는 변경하지 않습니다.
